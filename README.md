### Hi, I'm Gerald Kombo 👋

I build **civic-tech and agri-tech products for Kenya** — offline-first tools, market intelligence, and public-interest data platforms. Most of my work is agent-assisted (opencode.ai) and shipped end-to-end: design, build, deploy, verify.

#### Flagship

🌱 **[KilimoLink](https://github.com/geraldkombo/KilimoLink)** — hyperlocal food-resilience marketplace connecting Nairobi consumers directly with peri-urban farmers. AI pricing anchored to KNBS/AFA reference prices, county resilience dashboard. Live: **[kilimolink.pages.dev](https://kilimolink.pages.dev)** — SPA + API + D1 database, all on the edge.
